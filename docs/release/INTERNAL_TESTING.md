# Internal/Beta Testing Checklist

1. Upload Signed AAB ke Google Play Console → Internal testing, atau gunakan Firebase App Distribution.
2. Tambahkan minimal satu tester.
3. Install build release di perangkat Android.
4. Uji:
   - login email/password
   - Google OAuth
   - sinkronisasi profil Supabase
   - transaksi minyak jelantah
   - push notification/permission
   - pembayaran Premium Midtrans Sandbox
   - riwayat pembayaran
   - status Premium
   - logout/login kembali
5. Catat crash/bug dan hasil perbaikan.
6. Simpan screenshot halaman tester dan bukti instalasi sebagai lampiran laporan.
