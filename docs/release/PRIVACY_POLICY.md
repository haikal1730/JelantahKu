# Privacy Policy — JelantahKu

**Last updated: 10 September 2026**

JelantahKu adalah aplikasi untuk membantu pengelolaan minyak jelantah, transaksi pengguna, pembayaran Premium, dan operasional pickup.

## 1. Data yang kami proses

Kami dapat memproses email, nama, informasi profil, data transaksi minyak jelantah, informasi pembayaran/transaksi gateway, token push notification, dan data operasional pickup yang diperlukan untuk menjalankan fitur aplikasi.

## 2. Cara penggunaan data

Data digunakan untuk membuat dan mengelola akun, menyediakan fitur aplikasi, menyimpan riwayat transaksi, memproses pembayaran Premium, mengaktifkan subscription, mengirim notifikasi, serta mengelola pickup minyak jelantah.

## 3. Layanan pihak ketiga

JelantahKu menggunakan Supabase untuk authentication dan cloud database, Midtrans untuk pembayaran, dan Firebase Cloud Messaging untuk push notification. Masing-masing layanan dapat memproses data sesuai fungsi dan kebijakan privasinya sendiri.

## 4. Keamanan

Akses database dibatasi dengan authentication dan Row Level Security. Credential privileged seperti service-role key dan payment server key berada pada backend dan tidak boleh disimpan di aplikasi client.

## 5. Penyimpanan

Data akun dan data aplikasi yang diperlukan untuk layanan cloud disimpan pada layanan backend/cloud yang digunakan JelantahKu. Lama penyimpanan mengikuti kebutuhan operasional dan kewajiban yang berlaku.

## 6. Hak pengguna

Pengguna dapat meminta informasi mengenai data akunnya dan meminta penghapusan akun/data yang dapat dihapus, dengan tetap mempertimbangkan kebutuhan legal atau operasional yang wajib disimpan.

## 7. Perubahan kebijakan

Kebijakan ini dapat diperbarui apabila fitur, layanan pihak ketiga, atau cara pemrosesan data berubah.

## 8. Kontak

Untuk kebutuhan publikasi, ganti bagian ini dengan email resmi pengelola JelantahKu sebelum Privacy Policy ditempatkan pada URL publik.
